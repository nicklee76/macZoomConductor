Before you write

These are the things people hit first, and each has a quick answer.

The extension says "offline", or the app shows no windows

The extension talks to the browserNexus app on the same Mac. If the app is not running, the extension has nothing to talk to.

  1. Check that browserNexus is running — it lives in the menu bar.
  2. Open the extension's popup and press the reconnect button.
  3. Still nothing? Quit the app, start it again, and reload the extension.

Tab previews are blank, or say "No preview yet"

Previews need permission to read page contents, and browserNexus deliberately does not ask for it when you install the extension — so it is off until you turn it on.

  • Chrome: open the extension popup and click Enable previews, then Allow. If the dialog disappears before you can answer it — switching apps closes it — use chrome://extensions → browserNexus → Details → Site access → On all sites.
  • Firefox: about:addons → browserNexus → Permissions → Access your data for all websites.

Then switch tabs once. The first picture of a tab is taken when it becomes active.

Browsers can only photograph the tab that is actually on screen, so a background tab has no preview until you visit it. In Safari, pinned tabs have no preview at all — Safari offers no way to photograph them.

I use several browser profiles and only one shows up

Known limitation. browserNexus currently tracks one profile per browser at a time — whichever connected most recently. Support for several at once is planned.

Zoom is not what I set

Zoom comes from a cascade: a website exception outranks a tab, which outranks a window, which outranks the browser default. The badge beside each tab names the rule that decided, so open the app and look at the badge before assuming it is wrong. Sites listed under Exceptions are locked at 100% on purpose — some players break under page zoom.

macOS asks for permissions

  • Accessibility — needed to see where browser windows are and which display they are on.
  • Location — optional. Used only to label display history with a city. Refuse it and everything else works.

Reporting a bug

What helps most: what you did, what happened, what you expected, plus your browser and macOS versions. If the app is running, its logs are on your Mac at ~/Library/Application Support/com.browsernexus.app/Logs/ — nothing is sent anywhere unless you attach it yourself.
