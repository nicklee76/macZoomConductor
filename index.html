Core Capabilities

Built for Multi-Display Workflows

Engineered specifically to solve the friction of managing tabs and scaling across multiple screens on macOS.

Display-Aware Custom Zoom

Low-overhead macOS Accessibility tracking detects when a window is moved to an external 4K or ultrawide display, instantly adapting the zoom baseline without disrupting page layout.

Retina • 4K • 5K • Ultrawide

Persistent Window & Display Naming

Assign descriptive context tags to your browser windows (e.g. "Production Logs", "Research Notes", "Ticket Triage"). Window tags persist across app launches and session snapshots.

Contextual Window Labels

Instant Window & Tab Focus

Stop cycling through dozens of windows with ⌘~. Hit f or click Focus to immediately bring any window forward and activate the exact tab across Safari, Chrome, and Firefox.

Cross-Browser Direct Jump

Hierarchical Precedence Cascade

Deterministic rule resolution: Website Exceptions (strict 100% lock for maps/Figma) > Tab Overrides > Window Overrides > Display Defaults. Never conflicts.

Deterministic Rules Engine

Vi Keys & Global Hotkey (⇧⌘A)

Summon the command panel anywhere with ⇧⌘A (registered via Carbon HotKeys with zero Accessibility overhead). Navigate the tab tree with j/k and filter with /.

Vim Motion Ergonomics

Session History & Snapshots

Rotating local session recording. Inspect past window and tab layouts, view display assignments, and restore named workspaces with full zoom fidelity.

State Recovery & History

Frequently Asked Questions

browserNexus supports Safari (via native App Extension), Google Chrome (Manifest V3), and Mozilla Firefox. Brave, Microsoft Edge, Arc, and other Chromium-based browsers are also fully compatible via the Chrome extension.

browserNexus tracks window positions across displays using native macOS Accessibility (AX) and Quartz APIs. When a browser window moves from your built-in Retina screen to an external 4K monitor, browserNexus applies your configured monitor baseline zoom (e.g. 125%) while respecting individual tab overrides and site exceptions.

Yes. Window names are persisted in local atomic settings storage and matched against session metadata. When you restore windows through browserNexus or reopen your session, custom names re-attach automatically.

Unlike Electron apps or scripts that constantly poll the system every 500ms, browserNexus uses an event-driven architecture with native stdio messaging and UNIX domain sockets. When nothing is changing on screen, CPU consumption remains near zero, keeping your MacBook cool and preserving battery life.

Each license (Annual, Monthly, or Lifetime) permits installation on up to 2 personal Mac computers for a single user.
